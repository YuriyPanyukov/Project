# Тест-кейсы для приложения "Менеджер личной коллекции фильмов"

## Функция 1: Добавление фильма (Create)

### TC-1.1: Успешное добавление фильма со связями (Позитивный)
- **Связанная функция**: Добавление фильма в коллекцию (Операция 1)
- **Приоритет**: Высокий
- **Предусловия**: БД инициализирована. Существуют статус id=1, жанр id=1, персона id=1.
- **Тестовые данные**: title="Интерстеллар", duration=169, rating=8.7, status_id=1, genre_ids=[1], person_roles=[(1, "Режиссер")].
- **Шаги выполнения**:
  1. Открыть экран добавления фильма.
  2. Заполнить форму тестовыми данными.
  3. Нажать кнопку "Сохранить".
- **Ожидаемый результат**: Фильм добавлен, связи с жанром и персоной созданы. Отображается сообщение об успехе.
- **Постусловия**: В БД появилась запись в movies, movie_genres и movie_persons.

### TC-1.2: Добавление фильма с пустым названием (Негативный)
- **Связанная функция**: Добавление фильма в коллекцию
- **Приоритет**: Высокий
- **Предусловия**: Открыта форма добавления фильма.
- **Тестовые данные**: title="   " (пробелы), duration=120, rating=None, status_id=1.
- **Шаги выполнения**:
  1. Ввести пробелы в поле "Название".
  2. Заполнить остальные поля.
  3. Нажать "Сохранить".
- **Ожидаемый результат**: Ошибка валидации "Введите название фильма". Запись в БД не создана.

### TC-1.3: Добавление фильма с граничной оценкой 10.0 (Граничный)
- **Связанная функция**: Добавление фильма в коллекцию
- **Приоритет**: Средний
- **Предусловия**: Открыта форма добавления.
- **Тестовые данные**: title="Шедевр", duration=90, rating=10.0, status_id=1.
- **Шаги выполнения**:
  1. Ввести rating = 10.0.
  2. Нажать "Сохранить".
- **Ожидаемый результат**: Фильм успешно сохранен (CHECK constraint rating <= 10 соблюден).

## Функция 3: Удаление фильма (Delete)

### TC-3.1: Успешное удаление фильма (Позитивный)
- **Связанная функция**: Удаление фильма (Операция 3)
- **Приоритет**: Высокий
- **Предусловия**: В БД есть тестовый фильм id=10 с привязанными жанрами.
- **Тестовые данные**: movie_id=10, confirmed=true.
- **Шаги выполнения**:
  1. Нажать "Удалить" в карточке фильма.
  2. Подтвердить действие в модальном окне.
- **Ожидаемый результат**: Фильм удален из UI. Связи в movie_genres удалены автоматически (CASCADE).

### TC-3.2: Отмена удаления пользователем (Негативный)
- **Связанная функция**: Удаление фильма
- **Приоритет**: Высокий
- **Предусловия**: Открыта карточка фильма id=1.
- **Тестовые данные**: confirmed=false.
- **Шаги выполнения**:
  1. Нажать "Удалить".
  2. Нажать "Отмена" в модальном окне.
- **Ожидаемый результат**: Фильм остается в коллекции. DAO не вызывается.

### TC-3.3: Удаление несуществующего фильма (Граничный)
- **Связанная функция**: Удаление фильма
- **Приоритет**: Средний
- **Предусловия**: В БД нет фильма id=999.
- **Тестовые данные**: movie_id=999.
- **Шаги выполнения**:
  1. Попытаться удалить фильм id=999 (через API/прямой вызов).
- **Ожидаемый результат**: Возвращается сообщение "Фильм не найден". Ошибки приложения нет.

## Функция 8: Сохранение данных между запусками

### TC-8.1: Сохранение данных после перезапуска (Позитивный)
- **Связанная функция**: Сохранение данных
- **Приоритет**: Высокий
- **Предусловия**: Добавлен фильм "Тест" с оценкой 5.0.
- **Тестовые данные**: Фильм "Тест".
- **Шаги выполнения**:
  1. Закрыть приложение.
  2. Запустить приложение заново.
  3. Открыть список фильмов.
- **Ожидаемый результат**: Фильм "Тест" присутствует в списке с сохраненной оценкой.

### TC-8.2: Потеря данных при сбое записи (Негативный)
- **Связанная функция**: Сохранение данных
- **Приоритет**: Средний
- **Предусловия**: Имитация сбоя диска во время COMMIT транзакции.
- **Тестовые данные**: Составная операция (фильм + жанры).
- **Шаги выполнения**:
  1. Начать добавление фильма.
  2. Имитировать сбой БД.
- **Ожидаемый результат**: Транзакция откатывается (ROLLBACK). Частично сохраненных данных в БД нет.
