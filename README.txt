Проект: DAO-слой для «Менеджера личной коллекции (фильмы)»

Требования: Python 3.10 или новее. Внешние библиотеки не нужны.

Первый запуск:
1. Поместите все файлы в одну папку.
2. Откройте CMD/терминал в этой папке.
3. Выполните: python -c "import sqlite3; c=sqlite3.connect('movies.db'); c.executescript(open('init.sql', encoding='utf-8').read()); c.close()"
4. Запустите демонстрацию: python main.py
5. Запустите тесты: python -m unittest tests.py -v

Важно:
- init.sql создаёт структуру и добавляет тестовые записи.
- Если у вас уже есть movies.db с нужной схемой, сначала сделайте резервную копию.
- Названия ролей в тестовых данных: «Режиссер» (без ё), как в SQL-примере.
- Если в вашей существующей БД отличаются названия таблиц/полей или статусы, адаптируйте запросы к реальной схеме.
