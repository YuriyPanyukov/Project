# Проектирование пользовательского интерфейса: Менеджер личной коллекции фильмов

## 1. Полный список экранов приложения

На основе функциональных требований и макетов интерфейса выделены следующие экраны:

1. **Главный экран / Моя коллекция (Library)** — основной экран с сеткой постеров фильмов.
2. **Экран добавления фильма (Add Movie)** — форма для внесения нового фильма в базу.
3. **Карточка фильма (Movie Details)** — детальная информация о фильме, управление статусом и личными заметками.
4. **Экран фильтрации и поиска (Search & Filters)** — расширенный поиск по коллекции (может быть реализован как выезжающая панель или отдельный экран).
5. **Экран статистики (Statistics)** — графики и цифры по коллекции (сколько просмотрено, средний рейтинг и т.д.).
6. **Экран настроек (Settings)** — управление профилем, экспорт/импорт базы данных.

---

## 2. Описание каждого экрана

### 2.1. Главный экран / Моя коллекция (Library)
* **Назначение:** Быстрый просмотр всей коллекции фильмов и навигация по ней.
* **Элементы управления:**
  * Кнопка `+ Добавить фильм` (FAB — плавающая кнопка).
  * Строка поиска (Search bar).
  * Выпадающий список сортировки (По дате добавления, По алфавиту, По рейтингу).
  * Табы (вкладки) для быстрой фильтрации: «Все», «Хочу посмотреть», «Просмотрено».
  * Карточки фильмов (постер, название, год, звездный рейтинг).
  * Нижняя панель навигации (Коллекция, Статистика, Настройки).
* **Отображаемые данные:** Сетка постеров (изображения), названия фильмов (строка), год выпуска (число), личный рейтинг (визуализация звезд).
* **Действия пользователя:** Скроллинг, нажатие на карточку фильма (переход в детали), переключение табов, нажатие кнопки добавления.
* **Реакции системы:** Мгновенная фильтрация сетки при переключении табов или вводе текста в поиск.
* **Обработка ошибок:** Если коллекция пуста — отображается заглушка с иллюстрацией «Ваша коллекция пока пуста. Добавьте первый фильм!». При сбое загрузки обложек — отображается плейсхолдер с иконкой кинопленки.

### 2.2. Экран добавления фильма (Add Movie)
* **Назначение:** Внесение нового фильма в личную базу.
* **Элементы управления:**
  * Поле ввода `Название фильма` (с автодополнением из внешнего API, например, Кинопоиска).
  * Поле ввода `Год выпуска`.
  * Поле ввода `Режиссер`.
  * Выпадающий список `Жанр`.
  * Радиокнопки `Статус` (Хочу посмотреть / Просмотрено).
  * Кнопка `Сохранить`.
  * Кнопка `Отмена`.
* **Отображаемые данные:** Подгружаемый постер (если найден в API), поля формы.
* **Действия пользователя:** Заполнение полей, выбор статуса, сохранение или отмена.
* **Реакции системы:** Валидация полей (название обязательно), отправка данных на сервер, возврат на Главный экран с уведомлением «Фильм успешно добавлен».
* **Обработка ошибок:** Подсветка красным пустых обязательных полей. Сообщение «Фильм с таким названием и годом уже есть в вашей коллекции» при дубликате.

### 2.3. Карточка фильма (Movie Details)
* **Назначение:** Просмотр и редактирование информации о конкретном фильме.
* **Элементы управления:**
  * Кнопка `Назад` (стрелка).
  * Кнопка `Редактировать` (карандаш).
  * Кнопка `Удалить` (иконка корзины).
  * Переключатель статуса (Toggle) «Просмотрено».
  * Блок выставления рейтинга (5 кликабельных звезд).
  * Многострочное поле ввода для личной рецензии/заметки.
  * Кнопка `Сохранить заметку`.
* **Отображаемые данные:** Постер в высоком разрешении, название, год, режиссер, жанр, описание сюжета, текущий рейтинг, текст заметки (дата последнего редактирования).
* **Действия пользователя:** Изменение статуса, выставление звезд, написание заметки, удаление фильма.
* **Реакции системы:** Мгновенное сохранение рейтинга и статуса в базу (без перезагрузки страницы). При удалении — показ модального окна «Вы уверены, что хотите удалить фильм?».
* **Обработка ошибок:** Если поле заметки превышает лимит символов — блокировка ввода с подсказкой.

### 2.4. Экран статистики (Statistics)
* **Назначение:** Визуализация данных о просмотренном кино.
* **Элементы управления:**
  * Переключатель года (для просмотра статистики за конкретный год).
* **Отображаемые данные:** 
  * Общее количество фильмов (число).
  * Количество просмотренных (число).
  * Средний личный рейтинг (число).
  * Круговая диаграмма распределения по жанрам.
  * Столбчатая диаграмма просмотров по месяцам.
* **Действия пользователя:** Переключение периодов, наведение курсора на графики (для просмотра точных цифр).
* **Реакции системы:** Перерисовка графиков при смене периода.
* **Обработка ошибок:** Если данных для статистики нет — вывод сообщения «Недостаточно данных для построения графиков».

### 2.5. Экран настроек (Settings)
* **Назначение:** Управление аккаунтом и данными.
* **Элементы управления:**
  * Переключатель `Темная/Светлая тема`.
  * Кнопка `Экспорт коллекции` (в CSV/JSON).
  * Кнопка `Импорт коллекции`.
  * Кнопка `Очистить коллекцию` (опасная зона, красная кнопка).
  * Поле `Сменить пароль`.
* **Отображаемые данные:** Текущие настройки пользователя.
* **Действия пользователя:** Экспорт файла, смена темы, очистка данных.
* **Реакции системы:** Скачивание файла при экспорте. Модальное окно с двойным подтверждением при очистке коллекции.
* **Обработка ошибок:** При импорте неверного формата файла — сообщение «Ошибка формата файла. Поддерживаются только CSV и JSON».

## 3. Сценарии взаимодействия

### Сценарий 1: Добавление нового фильма в коллекцию
**Цель:** Добавить фильм «Интерстеллар» в личную базу.
1. Пользователь находится на главном экране (**Библиотека**).
2. Пользователь нажимает на плавающую кнопку **«+»**. Система открывает экран **«Добавить фильм»**.
3. Пользователь начинает вводить название «Интерстеллар» в поле ввода. Система отправляет запрос к внешнему API и предлагает варианты автодополнения.
4. Пользователь выбирает нужный вариант из списка. Система автоматически заполняет поля «Год» (2014) и «Режиссер» (Кристофер Нолан), а также подгружает постер.
5. Пользователь выбирает статус «Просмотрено» и нажимает кнопку **«Сохранить»**.
6. Система валидирует данные, отправляет POST-запрос на сервер, сохраняет фильм в БД и перенаправляет пользователя на экран **«Библиотека»** с уведомлением «Успешно добавлено».

### Сценарий 2: Выставление рейтинга и написание заметки
**Цель:** Оценить фильм «Начало» и оставить к нему личный комментарий.
1. На экране **«Библиотека»** пользователь кликает на постер фильма «Начало» (Inception).
2. Система открывает экран **«Сведения о фильме»** с подробной информацией.
3. Пользователь кликает на 4-ю звезду в блоке рейтинга.
4. Система отправляет PUT-запрос и сохраняет рейтинг `4` в БД. Звезды визуально закрашиваются.
5. Пользователь кликает в поле для рецензии и вводит текст: «Гениальный фильм, нужно пересмотреть».
6. Пользователь нажимает **«Сохранить заметку»**. Система сохраняет текст в БД и показывает зеленую галочку «Сохранено».

### Сценарий 3: Поиск и фильтрация коллекции
**Цель:** Найти нужный фильм в большой коллекции.
1. Пользователь заходит на экран **«Библиотека»**, где хранится 500 фильмов.
2. Пользователь нажимает на вкладку (таб) **«Хочу посмотреть»**.
3. Система мгновенно скрывает все просмотренные фильмы, оставляя только те, у которых статус «В планах».
4. Пользователь вводит в строку поиска слово «Звездные».
5. Система фильтрует текущий список и оставляет только фильмы с этим словом в названии (например, «Звездные войны»).
6. Если совпадений не найдено, система выводит заглушку «Ничего не найдено. Попробуйте изменить запрос».
