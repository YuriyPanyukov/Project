# Проектирование пользовательского интерфейса

## 1. Полный список экранов приложения

На основе анализа функциональных требований и макетов интерфейса выделены следующие экраны:

1. **Экран авторизации (Login)** — для входа в систему существующих пользователей.
2. **Экран регистрации (Register)** — для создания нового аккаунта.
3. **Главный экран / Каталог (Home/Catalog)** — отображение списка доступных товаров/услуг с возможностью поиска и фильтрации.
4. **Экран товара (Product Details)** — детальная информация о выбранном товаре, выбор количества, добавление в корзину.
5. **Корзина (Cart)** — просмотр выбранных товаров, изменение количества, удаление, переход к оформлению.
6. **Экран оформления заказа (Checkout)** — ввод адреса доставки, выбор способа оплаты, подтверждение заказа.
7. **Экран профиля пользователя (Profile)** — просмотр и редактирование личных данных, история заказов.

## 2. Описание каждого экрана

### 2.1. Экран авторизации (Login)
* **Назначение:** Предоставление доступа к персонализированным функциям приложения (корзина, история заказов).
* **Элементы управления:**
  * Поле ввода `Email` (валидация на формат email).
  * Поле ввода `Пароль` (скрытый текст).
  * Кнопка `Войти`.
  * Ссылка `Забыли пароль?`.
  * Кнопка-ссылка `Зарегистрироваться`.
* **Отображаемые данные:** Логотип приложения, поля для ввода.
* **Действия пользователя:** Ввод данных, нажатие кнопки «Войти», переход на экран регистрации.
* **Реакции системы:** 
  * При успехе: переход на Главный экран (Каталог).
  * При ошибке: вывод сообщения «Неверный email или пароль» под полями ввода.
* **Обработка ошибок:** Подсветка полей красным при пустом вводе или неверном формате email.

### 2.2. Главный экран / Каталог (Home/Catalog)
* **Назначение:** Просмотр ассортимента, поиск и выбор товаров.
* **Элементы управления:**
  * Строка поиска (`input`).
  * Выпадающий список `Сортировка` (по цене, по популярности).
  * Чекбоксы/фильтры по категориям.
  * Карточки товаров (изображение, название, цена, кнопка «В корзину»).
  * Нижняя панель навигации (Каталог, Корзина, Профиль).
* **Отображаемые данные:** Список товаров (загружается с сервера, формат JSON), изображения, цены (формат: `X XXX руб.`).
* **Действия пользователя:** Скроллинг, ввод поискового запроса, применение фильтров, добавление товара в корзину, переход в другие разделы.
* **Реакции системы:** Динамическое обновление списка товаров при поиске/фильтрации, обновление счетчика на иконке корзины при добавлении товара.
* **Обработка ошибок:** Если товары не найдены — вывод заглушки «По вашему запросу ничего не найдено». При потере сети — сообщение «Ошибка соединения. Проверьте интернет».

### 2.3. Корзина (Cart)
* **Назначение:** Просмотр и управление выбранными товарами перед оформлением заказа.
* **Элементы управления:**
  * Список добавленных товаров.
  * Кнопки `+` и `-` для изменения количества.
  * Иконка «Удалить» (корзина/крестик) для каждого товара.
  * Кнопка `Оформить заказ`.
* **Отображаемые данные:** Название товара, цена за 1 шт., итоговая сумма за позицию, общая сумма заказа.
* **Действия пользователя:** Изменение количества, удаление товаров, переход к оформлению.
* **Реакции системы:** Пересчет общей суммы при изменении количества, удаление позиции из списка.
* **Обработка ошибок:** Если корзина пуста, отображается сообщение «Ваша корзина пуста» и кнопка «Перейти в каталог». При попытке заказать больше, чем есть на складе — вывод предупреждения.

### 2.4. Экран оформления заказа (Checkout)
* **Назначение:** Ввод данных для доставки и оплаты, финальное подтверждение.
* **Элементы управления:**
  * Форма ввода адреса (Город, Улица, Дом, Квартира).
  * Радиокнопки выбора оплаты (Картой онлайн, Наличными при получении).
  * Кнопка `Подтвердить заказ`.
* **Отображаемые данные:** Итоговая сумма, состав заказа (кратко), сохраненный адрес из профиля (если есть).
* **Действия пользователя:** Заполнение формы, выбор способа оплаты, подтверждение.
* **Реакции системы:** Валидация полей, отправка запроса на сервер, очистка корзины, переход на экран «Успешный заказ» (или в профиль).
* **Обработка ошибок:** Подсветка незаполненных обязательных полей, сообщение «Выберите способ оплаты».

### 2.5. Экран профиля (Profile)
* **Назначение:** Управление личными данными и просмотр истории.
* **Элементы управления:**
  * Кнопка `Редактировать профиль`.
  * Вкладка `История заказов` (список).
  * Кнопка `Выйти` (Logout).
* **Отображаемые данные:** Имя пользователя, Email, телефон, список прошлых заказов (дата, сумма, статус).
* **Действия пользователя:** Просмотр данных, переход к редактированию, выход из аккаунта.
* **Реакции системы:** При выходе — очистка сессии и переход на экран Авторизации.
* **Обработка ошибок:** При невозможности загрузить историю — сообщение «Не удалось загрузить историю заказов».

## 3. Схема переходов между экранами

*Для отрисовки диаграммы можно использовать Mermaid (поддерживается в GitHub Markdown) или прикрепить картинку.*

```mermaid
stateDiagram-v2
    [*] --> Login : Запуск приложения
    
    Login --> Catalog : Успешный вход
    Login --> Register : Нажата кнопка "Зарегистрироваться"
    Register --> Catalog : Успешная регистрация
    
    Catalog --> ProductDetails : Клик по карточке товара
    ProductDetails --> Catalog : Кнопка "Назад"
    ProductDetails --> Cart : Добавление товара / Клик по корзине
    
    Catalog --> Cart : Клик по иконке корзины
    Cart --> Checkout : Кнопка "Оформить заказ"
    Checkout --> Catalog : Заказ успешно оформлен
    
    Catalog --> Profile : Клик по иконке профиля
    Profile --> Login : Нажата кнопка "Выйти"
    Profile --> EditProfile : Нажата кнопка "Редактировать"
    EditProfile --> Profile : Сохранение данных
