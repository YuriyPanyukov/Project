# Перечень тест-кейсов для итогового тестирования приложения

## Группа 1: Инициализация и системные проверки

### Тест-кейс SYS-01: Инициализация БД скриптом init.sql
* **Связанная функция:** `database.py` / `init.sql`
* **Приоритет:** Высокий
* **Предусловия:** База данных пуста или не создана.
* **Тестовые данные:** Скрипт `init.sql`.
* **Шаги выполнения:**
  1. Выполнить скрипт инициализации базы данных `init.sql`.
  2. Проверить наличие таблиц `movies` и `stats` (или аналогичных) в СУБД.
* **Ожидаемый результат:** Все таблицы, индексы и внешние ключи успешно созданы без ошибок синтаксиса SQL.

### Тест-кейс SYS-02: Сохранение данных между сессиями
* **Связанная функция:** Постоянство данных (Data Persistence)
* **Приоритет:** Высокий
* **Предусловия:** База данных инициализирована.
* **Тестовые данные:** Тестовый фильм "Интерстеллар" (2014).
* **Шаги выполнения:**
  1. Добавить фильм в БД через метод `movie_dao`.
  2. Перезапустить скрипт/приложение.
  3. Вызвать метод получения списка фильмов.
* **Ожидаемый результат:** Фильм "Интерстеллар" успешно извлекается из БД после перезапуска.

## Группа 2: Управление фильмами (CRUD в movie_dao)

### Тест-кейс MOV-01 (Позитивный): Добавление нового фильма со всеми валидными полями
* **Связанная функция:** `movie_dao.add_movie` (или аналогичный метод создания)
* **Приоритет:** Высокий
* **Предусловия:** Подключение к БД активно.
* **Тестовые данные:** Название: "Начало", Год: 2010, Длительность: 148.
* **Шаги выполнения:**
  1. Передать в метод добавления фильма валидный объект с тестовыми данными.
  2. Проверить возвращаемое значение (ID фильма).
* **Ожидаемый результат:** Метод возвращает валидный ID, фильм успешно записан в таблицу.

### Тест-кейс MOV-02 (Негативный): Попытка создания фильма с пустым названием
* **Связанная функция:** `movie_dao.add_movie` / Обработка некорректного ввода
* **Приоритет:** Высокий
* **Предусловия:** Подключение к БД активно.
* **Тестовые данные:** Название: `""` (пустая строка), Год: 2020.
* **Шаги выполнения:**
  1. Вызвать метод добавления, передав пустую строку вместо названия.
* **Ожидаемый результат:** Система генерирует ошибку валидации (например, `ValueError`), запись в БД не создается.

### Тест-кейс MOV-03 (Граничный): Валидация года выпуска фильма
* **Связанная функция:** Проверка бизнес-логики года выпуска
* **Приоритет:** Средний
* **Предусловия:** Подключение к БД активно.
* **Тестовые данные:** Год выпуска: `1888` (год выхода самого первого фильма в истории — "Сцена в саду Раундхэй").
* **Шаги выполнения:**
  1. Попробовать добавить фильм с годом выпуска 1888.
  2. Попробовать добавить фильм с годом выпуска на 1 год больше текущего (например, 2027).
* **Ожидаемый результат:** Фильм 1888 года успешно добавляется (нижняя граница). При попытке добавить фильм 2027 года система выдает ошибку (верхняя граница, фильм из будущего).

## Группа 3: Бизнес-логика и статистика (stats_dao)

### Тест-кейс STA-01 (Позитивный): Расчет агрегированной статистики по фильму
* **Связанная функция:** `stats_dao.get_movie_stats`
* **Приоритет:** Высокий
* **Предусловия:** В таблице статистики для фильма с ID=1 есть три оценки: 8, 9, 10.
* **Тестовые данные:** ID фильма = 1.
* **Шаги выполнения:**
  1. Вызвать метод получения статистики для фильма с ID=1.
* **Ожидаемый результат:** Метод возвращает среднюю оценку `9.0` и количество просмотров/оценок равное `3`.

### Тест-кейс STA-02 (Негативный): Запись отрицательного количества просмотров
* **Связанная функция:** Обработка некорректного ввода в статистику
* **Приоритет:** Высокий
* **Предусловия:** Существует фильм с ID=1.
* **Тестовые данные:** Количество просмотров: `-10`.
* **Шаги выполнения:**
  1. Попытаться обновить статистику фильма, передав количество просмотров `-10`.
* **Ожидаемый результат:** База данных (через `CHECK constraint`) либо код приложения отклоняют запрос, вызывая исключение. Отрицательные значения не сохраняются.

### Тест-кейс STA-03 (Работа с внешними ключами): Поиск несуществующего фильма в статистике
* **Связанная функция:** Поиск и фильтрация данных / Foreign Keys
* **Приоритет:** Высокий
* **Предусловия:** В БД отсутствует фильм с ID=999.
* **Тестовые данные:** ID фильма = 999.
* **Шаги выполнения:**
  1. Вызвать метод `stats_dao` для получения или записи статистики для ID=999.
* **Ожидаемый результат:** При получении возвращается пустой результат или `None` (обработано корректно). При попытке записи выбрасывается ошибка нарушения целостности внешнего ключа (Foreign Key Constraint).
